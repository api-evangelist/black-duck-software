# Black Duck Software

> Black Duck Software is an independent application security company (formerly the Synopsys Software Integrity Group, spun out October 2024, backed by Clearlake Capital and Francisco Partners). Its products span Software Composition Analysis (Black Duck SCA), static analysis (Coverity), dynamic/interactive testing, fuzzing, and the Polaris SaaS platform. Black Duck exposes a versioned REST API, the Detect CLI scanner, CI/CD plug-ins, webhooks, and an official MCP server (Black Duck Signal).

## APIs

- [Black Duck Hub REST API](https://documentation.blackduck.com/category/api): Per-tenant REST API over your Black Duck server; custom versioned media types, API-token-to-bearer auth, HAL-style hypermedia.
- [Getting Started with the API (Hub SDK)](https://documentation.blackduck.com/bundle/bd-hub/page/SDK/Using_the_Hub_SDK.html): How to mint an API token, authenticate, and call the REST API.

## Tools & SDKs

- [Detect (CLI scanner)](https://github.com/blackducksoftware/detect): Command-line scanner/orchestrator for Black Duck SCA.
- [blackduck (Python)](https://pypi.org/project/blackduck/): Official Python bindings for the Hub REST API.
- [blackduck-c-cpp (Python)](https://pypi.org/project/blackduck-c-cpp/): C/C++ build-capture scanning tool.
- [blackduck-common (Java)](https://github.com/blackducksoftware/blackduck-common): Shared Java integration library.
- [GitHub Organization](https://github.com/blackducksoftware): Official open-source repositories.
- [Black Duck Signal (MCP)](https://www.blackduck.com/signal-ai-appsec.html): Official MCP server for AI coding assistants.
